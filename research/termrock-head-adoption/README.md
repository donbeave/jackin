## Conclusions

1. **The bump is a measured 384-error mechanical migration, not a drop-in.** Pre-shim `cargo check` against head: jackin-tui 8, jackin-oppicker 1, jackin-launch 66, jackin-capsule 58, jackin-console 251 (+2 in `jackin` post-sweep). Dominant classes: `termrock::Theme` purge (305, → `style::DesignSystem`/`RolePalette`), `PanelEmphasis` → `PanelChrome` (24). A hidden pre-compile blocker: termrock head requires `serde ^1.0.229` (lock bump also adds `syn 3.0.3`, `base64 0.23.1`), and the cargo-deny bans gate then fails until two skip entries land (`base64@0.22.1`, `syn@2.0.119`); licenses/sources pass unchanged. All six crates reach a compiling fixpoint with mechanical shims in a disposable clone (final all-six `Finished` run not log-captured; re-verified post-hoc for jackin-tui — see chapter Method). → [01](01-compile-break-inventory.md)
2. **Only 40 of the 304 upstream migration docs apply to jackin❯'s imported surface** (33 first-pass + 7 caught by cross-checking the compiler inventory — the triage's false-negative rate is itself a finding: symbol greps miss docs that rename via a different symbol); 258 are internal/experience-layer build-out jackin never imported. Hard-break docs: 0060 (root re-export purge), 0061 (Theme/DesignSystem/PanelChrome), 0062 (FocusRing → InteractionScene), 0065 (ModalStack → OverlayStack), 0073 (`focused` → `cursor`), 0083 (`ListState::new`/`for_count` const-loss), 0085 (scroll offsets → ScrollAreaState), 0110/0152/0185/0196 + 0039/0057 (struct-literal → builder), 0261 (obsidian surface ladder), 0263 (DialogSpec fields), 0284 (Role variant changes); behavioral: 0288 (selection paint, backdrop wash), 0298 (status glyph roles). Preserved untouched: `scroll`, `DetailTable`, `HintSpan`/keymap, `osc`. → [02](02-migration-doc-map.md)
3. **Two APIs need redesign, not rename**: upstream made `FocusRing`/`ModalStack` crate-private — jackin-tui's `SurfaceFocus`/`ModalFlow` wrappers must move to `InteractionScene`/`FocusGraph`/`OverlayStack`; and `DiffViewState.offset` lost its public setter (12 sites in jackin-launch). `ListState::for_count` lost `const` (no upstream doc — reported upstream-worthy gap). → [01](01-compile-break-inventory.md)
4. **The bump alone visibly recolors brand-adjacent chrome.** 29 of the 38 old palette roles changed values; BrandHeader (console + launch duplicate) and capsule status-bar row 0 shift (chevron white→214,224,214; separator/label lose phosphor green; non-hovered tab fills vanish). Digital rain, warp animation, CLI rain, and the brand pill are immune (termrock-free `jackin-brand` constants). None of the 18 text snapshots catch this — they pin glyphs only. `RolePalette::terminal_native()` restores background-free surfaces but not old text values. → [03](03-theme-brand-impact.md)
5. **Upstream built the landing pad for exactly this migration.** Head commit `e1d61f4d` ("Jackin-TermRock parity", migration 0331) names jackin's pinned rev as the base, promotes `TerminalCellGrid`/`TerminalCellSource` and `ReadySubscription` for capsule/console needs, pins the tabs/dialog visual contracts, and excludes brand compositions by design. → [02](02-migration-doc-map.md), [04](04-component-adoption-candidates.md)
6. **The PNG baseline pipeline is adoptable from outside the TermRock workspace.** `termrock-raster` is git-dep-only (publish=false), deterministic by construction (vendored sha256-pinned JetBrains Mono 2.304, pure-Rust swash+tiny-skia, no OS text stack); all 107 upstream baselines reproduce bit-exact on this host (19–20 s). Adoption costs: same-rev pin for termrock+termrock-raster, jackin deny.toml BSD exceptions (tiny-skia, arrayref), REUSE annotations for committed PNGs, ~692 KiB per baseline set with permanent-history growth per re-bless. macOS↔Linux identity is measured-per-arch upstream but not cross-OS-proven. → [05](05-png-baseline-pipeline.md)
7. **Three contributor-docs pages pin soon-dead termrock names** (rg over `docs/content/reference/tui/`, 2026-08-19): `visual-design.mdx:10,24,64,76` (`Theme::default().style(role)`, `PanelEmphasis::Focused/Normal`), `dialogs.mdx:174` (the "`FocusRing` + `ModalStack` lifecycle" the head deletes), `navigation.mdx:24,26,142,249,359` (`FocusRing`, `PanelEmphasis`); 7 pages mention termrock overall. Repository law puts these in the bump PR's same-PR docs gate.
8. **Adoption candidates are mapped per surface with trade-offs** (no verdicts): console 19 machinery classes (largest: mouse subsystem, modal system, picker family), capsule 15-dialog layer + the 0331-purpose-built `TerminalCellGrid`/`StreamCoalescer` pane pipeline, launch progress/log/failure dialogs; small surfaces shrink as a consequence. Hand-rolled with no upstream pair (stays): capsule text selection, socket backend, mouse→PTY re-encode, prefix-key routing, file-browser sandbox policy, semantic save-diff. → [04](04-component-adoption-candidates.md)
9. **Mouse cutover (C14) is proceed-with-compensations, no upstream blocker.** 19-rule side-by-side matrix vs TermRock @ `29a16b5b`: 10 direct carriers, 2 cheap consumer configs (`.wheel_steps(1,1)`, wrap policy), 5 consumer carve-outs/compensations (Shift+wheel vertical fallback on `ScrollOutcome::Ignored`, scrollbar-drag lane, seam drag, precedence chain, deselect sentinel). Risk concentrates in Shift-fallback, scrollbar drag, seam drag (all MED, all with consumer routes). `ResizablePanelGroup` is NOT seam-drag parity (hit slack 0 vs ±1, absolute vs anchor-relative, min-size vs pct clamp, no width gate) — adoption needs an upstream change or a recorded consumer lane. → [06](06-mouse-subsystem-parity-matrix.md)
10. **Facade retirement is sequenced: `ModalFlow` console-exclusive-deletable; `ModalOutcome` deletable only after facade-internal `operator_info` migrates off it** (its public API returns `ModalOutcome<()>`, operator_info.rs:15,203,241). Console migration map: `UpdateResult` results all discarded (→ unit/EventResult), `SurfaceFocus` → `FocusGraph`+`FocusNode` (preserve TabBar-fallback + zero-area keyboard-only registration), `ModalFlow` → `OverlayStack` direct (fake-depth coupling dropped), `View`/`drive_frame` → plain fn + `Terminal::draw` (`runner::run` rejected — arch gate), blocking `Subscription` re-homed product-owned (upstream `ReadySubscription` has no `Pending`). Canonical `ModalOutcome` homes in jackin-oppicker (cycle-free). Capsule/launch keep `Component`/`View`/`drive_*`/`UpdateResult`/`NoEffect`/`SurfaceFocus` until their phases. → [07](07-facade-trait-retirement-inventory.md)

## Candidate directions (evidence in chapter 04; choice is the user's)

- **Bump-then-adopt per pairing table**: land the 384-error mechanical fixpoint first (shim-free, per migration docs), then per-surface modernization consumes the pairing tables. Cost: mechanical PR still recolors chrome (conclusion 4) — visual acceptance decisions land early.
- **OverlayStack-first modernization**: the modal/dialog machinery is triplicated (console/capsule/launch each carry `ModalRectSpec` twins); adopting `OverlayStack`/`dismissable` first deletes the most duplicated code but forces the `MuxMode` gating and Esc-policy re-verification across all three surfaces at once.
- **Pane-pipeline-first (capsule)**: `TerminalCellGrid` + `StreamCoalescer` were purpose-built for capsule's compositor per 0331; highest upstream-fit, but hyperlink/SGR region coverage is unverified (open unknown) and the terminal model must stay in `jackin-term`.
- **jackin-tui facade end-state — two irreconcilable options**: keep product runtime traits (`Component`/`View`/`Subscription`) or adopt upstream `event_result`/`runtime` contracts; both satisfy the arch gate, both cannot coexist (chapter 04 Dead ends). Decision-type question routed to the item.

## Ruled out

- **Waiting for a tagged release**: tags stop at v0.9.0, head Cargo says 0.11.0, migration docs index v0.14.0 — the version string is not a compatibility signal; pin by rev. → [02](02-migration-doc-map.md), [05](05-png-baseline-pipeline.md)
- **Compatibility facades over renamed APIs**: forbidden by item Must-not, repo law, and upstream directive alike (0061: "No deprecated aliases are provided. This is a hard break."). → [02](02-migration-doc-map.md)
- **Treating `patterns/*` as adoptable components**: they are copy-adapt recipes by their own headers; "adopt patterns/X" is a category error. → [04](04-component-adoption-candidates.md)
- **Expecting text snapshots to gate the visual migration**: all 18 are glyph-only; color regressions pass silently. → [03](03-theme-brand-impact.md)
