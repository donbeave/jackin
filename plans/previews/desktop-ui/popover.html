Agent handoff — how to match this look

1. Tokens: CSS variables in this file under [data-theme=dark|light] map to Swift: SF Pro, semantic Label/Secondary/Tertiary, phosphor #5CF07A dark / #0B774E light.

2. Materials: Popover = liquid glass chrome (GlassFallbacks); content cards = solid/inset fills. Footer dock = glass control layer. Sidebar glass in Usage window later.

2b. Scroll edges (critical craft): never hard-clip content mid-card. Use soft scroll-edge dissolve under sticky chrome / above footer. Native: scrollEdgeEffect(.soft) (WWDC25 / HIG Materials). H-scroll strips use the same soft left/right dissolve — no mid-tab cut.

2c. Open Usage CTA: glass capsule + phosphor tint (not solid green slab). Sits in sticky footer dock outside scrollers.

3. Metrics: 3 status levels only (high / mid / low + depleted). Default bands ≥40 / 15–39 / <15. Never brand-color meters. Brand color only on logo plates (template mono on menu bar).

3b. Strips: providers centered + H-scroll with edge fade; accounts left + H-scroll with edge fade.

3c. Detail templates: OpenAI, Anthropic, Amp, xAI, Kimi, Z.ai, MiniMax bucket order from Rust usage_bucket_order / probes.

4. Logos: Official PDFs from brand kits → template for status bar, optional original for in-popover plates. Preview SVGs are stand-ins.

5. Title: jackin + phosphor ❯ + desktop in primary label color (not phosphor).

6. For implementers: open this HTML in dark + light; screenshot both; match spacing (8pt), type steps, stack pattern (label → value → meter).

Status bar = transparent dual stack · meters = 3 status levels only · strips centered (providers) / left (accounts).
