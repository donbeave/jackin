Liquid Glass consistency check

Apple HIG: Liquid Glass = navigation / control layer floating above content. Do not glass the data layer. Our design follows that; verify it does not fight Tahoe.

✓ Glass (navigation)

Popover shell · sticky chrome · footer dock · context menu
Usage: unified titlebar + glass sidebar (Surge-class window chrome)

✓ Solid (content)

Metric tiles · Settings groups · buckets · meters/text
HIG: Liquid Glass is not for the content layer.

✓ Usage window quality

Traffic lights · titlebar actions as glass capsules · trailing sidebar % · soft content scroll. Pattern ref: high-end macOS utility (e.g. Surge Dashboard), not web dashboard.

✓ Soft scroll edges

Content dissolves under chrome / above footer — no mid-card hard clip.
Provider + account H-scroll soft-fade edges. Native: scrollEdgeEffect(.soft).

✓ Glass CTA (not green slab)

Open Usage = glass capsule + phosphor tint + hairline. jackin accent without fighting glass.

✓ Transparent menu bar

Template mono logos + dual stack — no chip fill.

⚠ Watch

Busy wallpapers: hairline + blur. Reduce Transparency → GlassFallbacks. Rain ≤ ~4% chrome; off with Reduce Motion / Transparency. Do not stack hard+soft edges.

Verdict: popover + Usage split is Liquid Glass–ready (nav glass, solid content, scroll edges). Native: GlassFallbacks + system scroll edge effects.
