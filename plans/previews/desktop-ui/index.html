Liquid Glass consistency check

Apple HIG: Liquid Glass = navigation / control layer floating above content. Do not glass the data layer. Our design follows that; verify it does not fight Tahoe.

✓ Glass (navigation)

Glance popover.html shell · status context menu · Usage sidebar · Usage toolbar
Matches Tahoe: bars, popovers, sidebars, menus.

✓ Solid (content)

Inset cards / buckets inside popover · Usage detail pane · meters/text
HIG: do not put Liquid Glass on the content layer.

✓ Transparent menu bar

Template mono logos + dual stack — no chip fill (matches popover status lock).

✓ jackin accent without fighting glass

Phosphor only on selection rings, CTAs, high-status metrics, j❯ — never full green glass.

✓ One popover artifact

Status left-click loads popover.html?embed=1 — same craft as the standalone template.

⚠ Watch

Busy wallpapers: hairline + blur. Reduce Transparency → GlassFallbacks ultraThinMaterial. Rain whisper ≤ ~4% chrome only; off with Reduce Motion / Transparency.

Verdict: approved popover + Usage nav/content split is Liquid Glass–consistent. Native implement only via GlassFallbacks.
