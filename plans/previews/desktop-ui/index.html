3. Metrics: 3 status levels only (high / mid / low + depleted). Default bands ≥40 / 15–39 / <15. Never brand-color meters. Brand color only on logo plates (template mono on menu bar).

3b. Strips: providers centered + H-scroll; accounts left + H-scroll.

3c. Detail templates: OpenAI, Anthropic, Amp, xAI, Kimi, Z.ai, MiniMax bucket order from Rust usage_bucket_order / probes.

4. Logos: Official PDFs from brand kits → template for status bar, optional original for in-popover plates. Preview SVGs are stand-ins.

5. Title: jackin + phosphor ❯ + desktop in primary label color (not phosphor).

6. For implementers: open this HTML in dark + light; screenshot both; match spacing (8pt), type steps, stack pattern (label → value → meter).
