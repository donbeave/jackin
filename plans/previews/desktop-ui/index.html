Liquid Glass consistency check

Apple HIG: Liquid Glass = navigation / control layer floating above content. Do not glass the data layer. Our design follows that; verify it does not fight Tahoe.

✓ Glass (navigation)

Glance popover shell · status context menu · Usage sidebar · Usage toolbar
Matches: bars, popovers, sidebars, menus on Tahoe.

✓ Solid (content)

Account cards · bucket bodies · Usage detail pane · meters/text
Matches: “don’t use Liquid Glass in the content layer.”

✓ Transparent menu bar

Status items are template-style, no chip chrome — correct for transparent Tahoe menu bar.

✓ jackin accent without fighting glass

Phosphor only on selection rings, CTAs, high-status metrics, j❯ — not full green glass.

⚠ Watch

Busy wallpapers under popover: keep hairline border + blur. Reduce Transparency → ultraThinMaterial fallback (GlassFallbacks).

⚠ Optional rain whisper

Keep opacity ≤ ~4% and only on chrome; off when Reduce Motion / Reduce Transparency.

Verdict: approved popover + Usage split is Liquid Glass–consistent. Implement only via GlassFallbacks.
