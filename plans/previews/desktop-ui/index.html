Interaction model (CONFIRMED)

Left-click status item → glance popover from popover.html (Providers mode, focused provider — not Overview).
Right-click → glass context menu (Open Usage / Refresh / Quit).
Status bar % = glance bucket only (Weekly for most providers, Daily for Amp) — same number as sidebar trailing % and Usage weekly/daily limit row.
Usage window = full usage_detail_presentation buckets + metadata (Session, Spark, Credits, Auth, …) — more detail than the bar, same fixture numbers.

Liquid Glass consistency check

Target: latest stable macOS (Tahoe 26) only for craft verification. Apple Adopting Liquid Glass · Liquid Glass · SwiftUI. Native: SwiftUI + GlassFallbacks (LG-A1–A12).

✓ LG-A1 Nav glass

Status: context menu glass · items template (not chips)
Popover: translucent panel shell + glass Refresh dock
Usage: floating glass sidebar · system glass toolbar

✓ LG-A2 Content not glass

Usage/Popover: limit lists, meters, credential rows = solid/inset only · no glassEffect on data

✓ LG-A3 Hierarchy

Provider full-fill selection ≠ account full-stroke pills · Overview vs Providers · nav vs detail

✓ LG-A4 / A5 Sparing · no stack

Custom glass only via GlassFallbacks · Tahoe system sidebar not double-glassed · one chrome layer

✓ LG-A6 Float over content

Usage HTML: one canvas · absolute floating sidebar
Native: NavigationSplitView + backgroundExtensionEffect

✓ LG-A7 Soft scroll edges

HTML main-scroll mask fades · native SoftScrollEdges on Usage + popover scrolls

✓ LG-A8 Toolbar group

Single Refresh action group (Usage toolbar · popover footer) — not scattered CTAs

✓ LG-A9 Selective tint

Phosphor on selection + glass Refresh glyph/tint + high metrics + j❯ — never solid green slabs

✓ LG-A10 Regular glass

Popover uses glassEffect(.regular) · fallback ultraThin for Reduce Transparency only

✓ LG-A11 Latest SDK

Craft verified for macOS 26 Tahoe · release builds require macOS 26 SDK

✓ LG-A12 SwiftUI only

NavigationSplitView · toolbar · list sidebar · UniFFI data · no UIKit chrome path

✓ FB1-60 De-slop

Full continuous strokes only · no one-sided borders · no multi-shadow AI pills
